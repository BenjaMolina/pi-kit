# Add reversible Pi Antigravity prompt repair
Objective: Add a reversible Pi `before_provider_request` prompt sanitizer in `pi-kit` scoped strictly to Antigravity models on `cliproxyapi` and `9router`, preserving local Pi docs paths and providing an environment opt-out flag (`PI_KIT_ANTIGRAVITY_PROMPT_REPAIR`).
Branch: `feat/pi-antigravity-prompt-repair` | Delivery strategy: `single-pr` (689 authored lines including tests/docs, user confirmed Single PR) | Runner: `bun test ./tests/`

## Specs

- **S1 — Strict Antigravity model scoping ("acotado solo a modelos Antigravity"):** Intercept outgoing Pi OpenAI-completions requests via `before_provider_request` only when `ctx.model?.provider` is `"cliproxyapi"` or `"9router"` and the target wire model resolves to an Antigravity route (`ag/*` or `antigravity/*` on `9router`; `agy*/*`, `ag/*`, `antigravity*/*`, unscoped `gemini-*` / `gpt-oss-*`, or `/v1/models` `owned_by: "antigravity"` for ambiguous unscoped IDs on `cliproxyapi`). Leave non-Antigravity providers and models (`cx/*`, `codex*`, `gpt-*` except `gpt-oss-*`, direct `claude-*` not owned by `antigravity`, etc.) completely untouched.
- **S2 — Surgical prompt rewrite preserving docs paths ("reescribiendo sin perder rutas de docs"):** Rewrite only `"system"` and `"developer"` instruction messages (`string` or text-part array) without mutating `user`, `assistant`, `tool`, or persisted session history. Replace `"operating inside pi, a coding agent harness"` with `"working on software projects"`, and rewrite Pi's `Pi documentation (read only when the user asks about pi itself...)` boilerplate (both plain-text Pi `v0.85.x` and `<docs>...</docs>` Pi `v1.4+`) into neutral reference text that preserves verbatim the `Main documentation`, `Additional docs`, and `Examples` filesystem paths plus all `.md` / `examples/` topic filenames. Keep rewrites idempotent and fail open (`return undefined`) on non-matching or malformed payloads.
- **S3 — Reversible environment kill-switch ("y con flag para apagarlo"):** Enable the repair by default in `extensions/antigravity-prompt-repair.ts` and disable it immediately with zero network or payload work when `PI_KIT_ANTIGRAVITY_PROMPT_REPAIR` is set to `0`, `false`, `no`, or `off` (case-insensitive). Document the extension and opt-out flag in `README.md` and assert packaged presence in `scripts/pack-consumer.ts`.
- **S4 — Live full Explorer prompt and Pi RPC verification ("empezando por verificar que el prompt completo de Explorer pase en 200 OK"):** Verify that the complete ~33.9 KB Pi `v1.4.0` `gentle-ai-explore` prompt (with skills, extensions, Engram instructions, and tools) returns `200 OK` against live `CLIProxyAPI` (`gemini-4-argon-high`) and `9Router` (`ag/gemini-4-argon-high`), and verify end-to-end execution through a real `pi` CLI subagent-style invocation loading `extensions/antigravity-prompt-repair.ts`.
